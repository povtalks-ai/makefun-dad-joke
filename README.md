One original dad joke, 80 characters, written to be told out loud.

> Why did the dad bring a pencil to the job interview? He wanted to draw a salary.

Built for the [make.fun "Dad Joke Showdown" bounty](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5), $5 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) checks the line is a single line of 1 to 199 characters and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), so both runs write the same bytes. No network, nothing else read or written.
